## 支付关闭版本（可选先行方案）

若真实支付未就绪而需要先行发布，须满足：

1. **支付入口隐藏**：充值页、组合支付差额入口在正式版中隐藏或置灰，仅保留浏览 / 未支付下单能力。
2. **kill switch**：提供后端配置开关，可随时整体关闭支付相关入口与提示，不依赖发版。
3. **二次开放门禁**：开放支付入口必须经过 FP-3 阶段二验收 + FP-4 回验双门禁。

## 验收标准

- 真机与体验版走查通过，核心流程无阻断。
- 微信官方审核通过，正式版可正常访问。
- 正式版下充值 / 组合支付 / 券核销端到端可用（或支付关闭版本入口正确隐藏）。
- 有赞下线（FP-2）前，正式版已稳定运行并完成回验。
