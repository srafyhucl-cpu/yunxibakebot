# 规则目录说明

本目录用于维护**运行时直接生效**的统一业务规则。每个文件只负责一类规则面，避免把配送、售后、发票、商品通用规则混写在一处。

## 当前主文档

- `订购与履约规则.md`
  - 预订提前量、退改、配送与自提、营业时间、截单、门店地址
- `商品通用规则.md`
  - 奶油与保存、配件标配、额外收费
- `售后规则.md`
  - 配送损坏、漏发配件、配送超时的规则与话术
- `企业服务规则.md`
  - 企业团购、折扣、发票

## 维护原则

- 同一条通用规则只能在一个文件维护
- 新增规则时，优先判断是否属于现有 4 个文件之一
- 只有当现有文件职责明显混杂时，才考虑新增规则文档

## 入库说明

本目录下不会自动全量扫描全部文件，当前仅 `scripts/seed_knowledge.py` 中启用的主文档会直接导入 `knowledge_base`。
