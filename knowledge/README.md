# 知识库目录首页

`knowledge/` 目录按“单一职责、中等粒度”组织，运行时只让真正的知识源文档入库，说明文档与参考文档不直接入库。

## 一、目录结构

- `芸熙烘焙商品库知识库.md`
  - 商品主数据
- `规则/`
  - 统一业务规则源
- `FAQ/`
  - 高频问答与选购问答
- `话术/`
  - 客服沟通话术
- `参考/`
  - 非运行时事实来源的参考资料
- `芸熙AI客服指引_Prompt.md`
  - 提示词参考与流程规范
- `知识源说明.md`
  - 维护规则与入库说明

## 二、维护入口

### 1. 商品信息

改这里：`芸熙烘焙商品库知识库.md`

适用内容：

- 商品名称
- 规格价格
- 配送方式
- 可选夹心
- 胚底
- 甜度
- 商品级卖点

### 2. 通用规则

改这里：`规则/`

当前主文档：

- `订购与履约规则.md`
- `商品通用规则.md`
- `售后规则.md`
- `企业服务规则.md`

### 3. FAQ

改这里：`FAQ/`

当前主文档：

- `基础服务FAQ.md`
- `商品选购FAQ.md`
- `场景与会员FAQ.md`

### 4. 话术

改这里：`话术/`

当前主文档：

- `下单引导话术.md`
- `售后安抚话术.md`

### 5. 参考资料

改这里：`参考/`

当前主文档：

- `主推款参考.md`

注意：运行时主推款仍以后台配置 `shop_config.featured_products` 为准。

## 三、哪些文档会直接入库

会直接入库：

- `芸熙烘焙商品库知识库.md`
- `规则/` 下的主知识文档
- `FAQ/` 下的主知识文档
- `话术/` 下的主知识文档

不会直接入库：

- `README.md`
- `知识源说明.md`
- `芸熙AI客服指引_Prompt.md`
- `参考/` 下的参考资料

## 四、修改后的收口动作

1. 修改正确的知识文档
2. 执行 `python scripts/seed_knowledge.py`
3. 重建向量索引
4. 更新 `LOGBOOK.md`
