# 话术目录说明

本目录用于维护**客服表达模板**。这里的内容重点是“怎么说”，不是“规则事实本身是什么”。

## 当前主文档

- `下单引导话术.md`
  - 售前咨询、下单确认、配送说明、价格说明等引导类话术
- `售后安抚话术.md`
  - 售后安抚、补偿沟通类话术

## 维护原则

- 规则事实先写到 `knowledge/规则/`
- 话术目录只沉淀表达模板、沟通语气与回复结构
- 若一段话术依赖具体规则，规则变更时应同步检查对应话术是否需要调整

## 入库说明

本目录下当前启用的主文档会由 `scripts/seed_knowledge.py` 解析为话术条目并导入 `knowledge_base`。
