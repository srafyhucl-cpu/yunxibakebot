# FAQ 目录说明

本目录用于维护**问答式知识**。这里只放顾客高频会问、且适合用问答表达的内容，不放统一业务规则原文，也不放流程性客服话术。

## 当前主文档

- `基础服务FAQ.md`
  - 尺寸、甜度、夹心、胚底等基础短问答
- `商品选购FAQ.md`
  - 选购决策相关问答，如展示、定制、过敏原、配送体验等
- `场景与会员FAQ.md`
  - 节日场景推荐、积分等问答

## 维护原则

- 简短稳定的问题放 FAQ
- 如果某条内容已经升级为统一规则，应改到 `knowledge/规则/`，不要在 FAQ 重复维护
- 如果某条内容更像客服回复模板，应改到 `knowledge/话术/`

## 入库说明

本目录下当前启用的主文档会由 `scripts/seed_knowledge.py` 解析为 FAQ 条目并导入 `knowledge_base`。
